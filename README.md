# Corrida Maluca

Jogo de corrida para navegador desenvolvido com HTML5 Canvas, CSS e JavaScript puro. O arquivo principal do jogo é `jogo-corrida.html`.

## Como jogar

- Desvie dos carros adversários mudando de faixa.
- Colete estrelas para aumentar a pontuação.
- Tente sobreviver enquanto a velocidade e a dificuldade aumentam.

Os controles disponíveis são apresentados na interface do próprio jogo; o arquivo também inclui controles por teclado e opções para telas sensíveis ao toque.

## Executar localmente

Não é necessário instalar dependências.

1. Clone ou baixe este repositório.
2. Abra `jogo-corrida.html` em um navegador moderno.

Opcionalmente, inicie um servidor local:

```bash
python -m http.server 8000
```

Acesse `http://localhost:8000/jogo-corrida.html`.
